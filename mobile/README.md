# AI Stock Trend Mobile

Mobile client for the AI Stock Trend Prediction project. The app uses Expo Router, NativeWind/Gluestack styling, and Zustand for shared UI state.

## Development

```bash
npm install
npm run android
```

## Structure

- `src/app`: Expo Router entry points.
- `src/features`: product screens and feature modules.
- `src/shared`: reusable design tokens and shared components.
- `src/stores`: Zustand stores.
- `components/ui`: generated Gluestack primitives.
